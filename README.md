# AuditRoute — Landing page

Landing page de alta conversión para un software de control de combustible y rutas, construida con Next.js, React, TypeScript y Tailwind CSS.

Requiere Node.js 20.9 o una versión posterior.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Compilar para producción

```bash
npm run build
npm start
```

## Notas de contenido

- El caso de estudio se presenta explícitamente como una simulación ilustrativa.
- La calculadora usa un potencial de optimización del 12%; debe ajustarse con datos reales antes de publicar.
- Los precios y datos de contacto son demostrativos y deben validarse antes de lanzamiento.

La tasa de ahorro y el precio mensual están centralizados en las constantes
`SAVINGS_RATE` y `MONTHLY_PRICE_PER_VEHICLE` de `app/page.tsx`.
